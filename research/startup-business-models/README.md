# Startup Business Models Research Library

A 13-document research library on how startups actually work — business models, pricing, money, fundraising, investors, networks, and failure — written for a smart, technical, first-time founder (Bharat: NYC-based, pre-idea with candidate directions) who is new to the startup world's jargon, unwritten rules, and norms. Every document defines its terms in plain language, tags each claim **[Evergreen]** (true for decades) or **[2026]** (current-era numbers that will drift), includes worked examples with real arithmetic, and cites primary sources. Start with the playbook; use the numbered docs as deep-dive references.
